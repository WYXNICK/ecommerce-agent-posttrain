# 历史实验档案：200题协议

本目录保留早期200题协议的SFT、GRPO与E1/E2/E3实验。当前项目主结果采用独立test1000，见[核心结果](../results.md)；本目录中的“主结果”仅指该历史系列。

## 历史主结果：Chat 评测协议

主结果沿用原 `/v1/chat/completions` 执行入口，统一按 Final-200、原始 Reward v3
计分。精确数值与逐题成功 ID 以 [E1 结果数据](grpo-e1-results.json) 为准。

| 模型 | 严格成功 | 成功率 | 平均原始奖励 | 平均工具步数 |
|---|---:|---:|---:|---:|
| SFT | 131/200 | 65.5% | 0.558408 | 9.555 |
| 上一版 GRPO（step 450） | 132/200 | 66.0% | 0.559420 | 10.275 |
| E1（step 500） | 138/200 | 69.0% | 0.598075 | 10.375 |

这些分数是原入口的有效端到端结果；异常和不可验证奖励均保留在 200 题分母中。
E1 相比 SFT 增加 3.5 个百分点，但单次评测未达到统计显著，且 E1 包含共享
Action Guard 修复，不能把差异全部归因于训练。该固定集合已用于迭代分析，
适合回归比较；进一步证明泛化能力需要新的独立测试集。E2 尚未按原协议评测。
