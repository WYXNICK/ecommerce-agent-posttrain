# 阶段 3：教师轨迹采集

## 目的与实现

让强模型真实操作购物环境，生成可直接训练学生的完整成功示范。教师只看 Actor 可见信息；严格 JSON 动作转成统一工具调用，由共享守卫在真实环境执行，不需要教师 logits、tokenizer 或私有思维链。

Sol 固定为 `gpt-6.1-sol-2026-09-29`，Astra 固定为 `gpt-6-astra-2026-09-03`，均为 high 推理；环境、观察、工具和学生可见预算与 Baseline 一致。使用 4,000 道训练候选和 800 道验证候选，按九领域配额独立采集；每教师 6 路并发。429 最多尝试 12 次，等待 2/4/8/16 秒后每次 20 秒；耗尽后保存进度退出，可在同协议下续跑。HTTP 重试不重复执行环境动作。

只有完整严格成功、通过学生模板/长度/监督检查且 task ID 唯一的轨迹才进入成品。基础设施失败与模型行为失败分别记录；原始轨迹及失败保留为证据，不把失败样本静默计成成功。

Sol 于北京时间 **2026-10-28 22:01** 完成，Astra 于 **2026-10-30 03:54** 完成。实际每个任务只有一次非基础设施故障的行为尝试，没有靠行为重采得到上述成功率。Sol 训练侧排除 3 次基础设施中断；Astra 排除 1 次，另有 1 条奖励不可核验执行保守计为非成功。包含基础设施中断的训练产出率分别为 81.57% / 82.10%。完整失败分类见 [Sol](../../results/teacher-collection/sol/summary.json)、[Astra](../../results/teacher-collection/astra/summary.json)。

## 验收、成品与下一步

- 成品与严格成功原始证据逐条一致，教师快照一致；领域配额、唯一任务、模板长度和 assistant 监督范围通过验收。
- 训练/验证交集为零，训练与受保护留出集合无重叠；继承证据的原始文件哈希不变。
- 已发布 [Sol](../../data/teacher/sol/manifest.json) 与 [Astra](../../data/teacher/astra/manifest.json) 数据成品，各含 `train.jsonl.gz` 2,000 条、`validation.jsonl.gz` 200 条；解压后与验收成品逐字节一致，压缩与原文 SHA-256 均记录在 manifest。
- 原始轨迹、重试、usage 和完整验收记录保留在本地 `next/outputs/teacher-parallel/` 及只读继承源；成品是训练输入，不能替代原始终局证据。API 未返回的重试费用未伪称完整计费。
- 两套训练成品共有 **1,928 个任务**，合计为 **2,072 个独立任务、4,000 条示范**，不能称为 4,000 个独立训练任务。若做教师数据对照，还须匹配任务和监督 token 预算。

两套成品均可用于新版 SFT。先沿用计划中的 Sol 主线，Astra 保留为独立数据版本；不根据测试集差异调配或筛选训练数据。初始示范可以重复训练，后续两轮失败回流仍需教师真实接管。新版 SFT、失败回流和 GRPO 尚未执行。

## 教师正式评测如何安排

两位教师的正式 1,000 题评测均已完成，Sol **80.4%**、Astra **80.9%**，详见[评测阶段](../teacher-evaluation/README.md)。采集成功率与测试成绩分开，不根据测试失败改题或回流测试轨迹，也不把教师成绩称为学生的理论上限。

原项目曾报告 DeepSeek V4 Flash 的历史 Final-200 结果 139/200（69.5%），后来的 75.96% 是删题后的分母重算；与新版测试或 Sol 采集成功率均不可直接比较。[原项目审计](https://github.com/YYHDBL/shopping-grpo-longhorizon/blob/main/docs/evaluation-updates.md)
