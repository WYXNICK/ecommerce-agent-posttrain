# 教师 API 用量与费用

## 统计范围

本轮两位教师的正式训练/验证采集和各 1,000 题正式评测；只读继承的轨迹计入一次，包含成功与失败执行中 API 已返回的 usage。不包含这些运行之外的独立试采、历史实验或未返回用量的重试。权威汇总及原始证据哈希见 [teachers.json](../results/usage/teachers.json)。

## 已报告 token

| 阶段 | Astra | Sol |
|---|---:|---:|
| 训练轨迹采集 | 173,948,850 | 193,360,820 |
| 验证轨迹采集 | 16,762,389 | 18,190,012 |
| 正式 1,000 题评测 | 70,945,327 | 79,070,330 |
| **合计** | **261,656,566** | **290,621,162** |

两位教师合计 **552,277,728 token**，其中 prompt **546,562,690**、completion **5,715,038**。API 用量包含每次调用重复发送的上下文，不能等同于 SFT 成品长度或监督 token 数。

逐请求原始轨迹已记录模型身份、usage、推理 token、缓存命中/缓存写入 token、延迟及传输重试。本页汇总来自原始证据，并与各阶段 `summary.json` 的输入、输出、总量及推理用量逐项核对。

- `total_tokens = prompt_tokens + completion_tokens`。
- reasoning token 已包含在 completion 中，不再次累加。
- 缓存命中与写入是 API 报告的 prompt 明细，不再次加到输入或总量；实际计费口径由 ModelHub 决定。
- Sol 有 3 次、Astra 有 1 次模型调用未返回 usage；另有 2,428 / 644 次传输重试没有单独的 usage。这不表示所有重试都收费，也不能视为已完整覆盖所有消耗。

## 费用状态

**实际金额与估算金额均未核算，状态为待对账，不是 0。** 当前尚无本次 ModelHub 的实际价目、缓存读写计费规则及账单，不能把总 token 乘统一单价，也不能用 OpenAI 直连公开价格冒充该网关的实际费用。

`teachers.json` 将 `actual_cost`、`estimated_cost` 和币种保留为 `null`，同时保存可用于后续核算的输入、输出、推理及缓存明细。本统计不包含本地 GPU 资源费用。
