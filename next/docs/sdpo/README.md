# SDPO：反馈纠正与成功行为保护

**状态：已完成，未获得净提升。** 200步完成，按开发集规则保留原修复SFT（step0）；见[结果](r2-results.md)。 R2从修复SFT重新训练，不从R1续训。原终局GRPO仍是主结果。

## 目的与依据

R1开发集选中的step150在test1000为756/1000，低于修复SFT的766和原终局GRPO的778。后期退化；成功轨迹也被另一条成功路线重新指导，失败反馈重复展示完整失败动作。R2只针对这些监督风险修订，不更换任务、模型或评测口径。

- R1保留：[方法](r1-method.md)、[训练结果](results.md)、[测试结果](test-results.md)、[冻结配置](../../results/sdpo/r1/run.json)。
- 方法来源：[SDPO论文](https://arxiv.org/abs/2601.20802)，R2的成功保护为本项目扩展，不冒充论文原配方。

## 本轮实现

| 轨迹 | 教师与监督 |
|---|---|
| 严格成功 | 原上下文、冻结修复SFT的概率分布；不加入另一条成功路线。通过禁用新SDPO LoRA得到基座，无需额外复制模型 |
| 失败且有具体可验证约束、动作拒绝或同题成功示范 | EMA自教师＋反馈，在原学生动作token上做全词表reverse KL |
| 只有笼统失败标签、也没有成功示范 | 不进入蒸馏；保留轨迹与排除计数 |
| 基础设施失败或不可验证 | 维持原排除规则，不作为示范或训练目标 |

失败反馈保留结果、具体失败约束、被拒绝的动作及理由；移除整条`executed_actions`。保留每一步之前真实的工具历史，不把未来完整失败路线塞进各步输入。成功示范来自当前同题实际执行成功的轨迹，不读取隐藏目标答案。

目标为全部有效动作token上的平均`w × KL(学生 || stopgrad(目标教师))`，两类样本等token权重，不额外调混合系数。`w`是原有上限2的停止梯度采样校正。成功约束和失败蒸馏分别记录KL及token数；成功样本的教师logprob差表示与冻结SFT的差，不与R1的反馈教师诊断混为一谈。

## 固定配置与停止规则

权威配置：[sdpo.json](../../configs/sdpo.json)，继承[grpo.json](../../configs/grpo.json)。每轮完整配置与源码指纹写入`run.json`。

- 起点：S-repair step72；原2,000题训练池，保护验证/dev/test及重复组。
- 每次更新2题×8条，单波1题×8条；双H100同步梯度、FLA/SDPA、BF16 LoRA rank16/alpha32。
- LR 1e-6、15步warmup、EMA 0.01、梯度裁剪1；上下文、动作预算与正式评测协议保持不变。
- **最多200次有效更新，每50步保存并评测dev300**；起点参与选模，严格成功数优先，其次Reward v3、较少动作、较早步数。
- 不因一次dev波动自动停训；达到200步正常结束。数值异常、服务失败或连续无有效批次时失败退出并保留证据。
- 结束后导出选中与最终模型；开发集选模不等于测试收益。本轮不自动执行test1000或pass@k。

200步是保守首轮预算，不是已验证的最优长度。正确的蒸馏计算也不保证自教师能提供有效纠正；本轮不承诺超过原终局GRPO。

## 验证与运行证据

必要验证覆盖：反馈来源和筛选、成功样本原上下文、冻结基座不受LoRA/EMA改变影响、教师恢复、全词表KL数值/梯度、双卡归一化；再做一批真实双卡前向/反向验证（不更新参数）。通过后直接启动正式训练，不反复进行小规模试跑。

- 训练：`outputs/sdpo/r2/`；验证：`outputs/sdpo/r2-validation/`。
- 结果清单：`results/sdpo/r2/`；结束后汇总：`r2-results.md`。
- 日志：`train.log`、`metrics.jsonl`、`tensorboard/`；轨迹：`rollouts/`；评测：`dev/step-*/`、`selection.json`。
- 每50步检查点及关键日志先校验备份到开发机，再排队归档HDFS；正常结束或可捕获失败自动恢复两卡保活。强制回收只能依靠已落盘备份。
- 后台使用已有`launch.sh --variant sdpo`入口，SSH断联不终止进程；运行时保活让出GPU给有效训练。

验收完成：51项相关测试通过，真实双卡一批16条轨迹、2,736个动作token完成前向与反向，优化器更新0次；峰值分配显存约7.30/7.24GiB（不含vLLM），采样/训练平均logprob差0.00087。见[验收结果](../../results/sdpo/r2/validation.json)。这验证计算链路，不证明反馈教师的实际纠错收益。
