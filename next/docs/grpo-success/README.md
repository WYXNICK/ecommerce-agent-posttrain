# 严格成功优先的约束型 GRPO

**状态：实现与离线验证已完成；尚未启动训练。** 本版继承约束奖励的证据判定，改进奖励目标和更新组选择。原终局 GRPO 仍为正式主结果。

## 1. 当前结果说明了什么

同一 test1000：修复 SFT 为766次成功，原终局GRPO为778次，约束版step450/500均为776次。约束版step450的错误购买26→12、Reward提高，但循环24→31、平均动作8.50→9.20；它改变了行为取舍，没有实现整体超越。错误购买分类不等于全部约束违反，不能据此宣称消除了reward hacking。

本次只对**约束版已有训练轨迹**审计，不读取测试题来构造训练数据或奖励规则：

| 训练证据 | 结果 |
|---|---:|
| 完整生成轨迹／组 | 12,600条／3,150组 |
| 实际更新的组 | 1,000组 |
| 更新组中没有严格成功的组 | 177组（17.7%） |
| 获得正优势的未成功轨迹 | 361条：全失败组354条，混合组7条 |
| 其中循环／回复预算耗尽 | 110条／188条 |
| 正优势未成功轨迹的动作token | 209,751，占全部更新动作token约14.0% |

例如`[-0.65, -0.65, -0.85, -0.65]`的组内优势为`[+0.05,+0.05,-0.15,+0.05]`。压低违约购买后，相对更好的失败仍被强化。即使组内有成功，`[1,0.193,-0.65,-0.85]`中的部分购买也能获得正优势。

这**不是GRPO均值计算错误**，而是分级奖励优化目标与“严格成功率优先”的目标存在差别。该信号确实存在，但不能证明它独自造成全部退化；原有成功丢失、单种子方差及未采到正确解的困难任务仍是限制。[完整审计](../../results/grpo/success/audit.json)。

## 2. 唯一改进：成功优先、失败保留排序

先沿用现有[约束奖励](../grpo-constraints/README.md)，得到`r_c`：确认违约为−0.85，模型失败原值不变；基础设施问题和无充分证据的不可验证轨迹仍为`None`。原环境评分和轨迹字段保持原样。

设`G=4`，`L=−0.85`（读取环境的错误购买奖励），训练奖励为：

```text
严格成功：R = 1
可训练但未严格成功：R = (r_c - 1) / [G × (1 - L)]
不可训练：R = None
```

严格成功直接复用正式评测判定，要求完整、可验证的`gold_purchase`，不能只判断reward等于1。

因此失败奖励位于`[-1/G, 0]`；确认违约为−0.25，循环/预算耗尽约为−0.223，部分匹配仍保留高低排序。该区间由组大小确定，不新增成功奖金、长度惩罚或需要搜索的奖励权重。

**只更新同题同时包含严格成功和失败的完整组。** 全成功、全失败和未解决基础设施异常组跳过，沿用最多8波补采、每步2组、连续10轮无可用批次则停止。全失败题不永久删除，下次采样出现成功后仍可进入训练；轨迹继续保留。

组内优势仍为`A = R - mean(R)`，不裁剪优势或单独掩掉失败梯度。对任何被接受的组：

- 成功轨迹严格为正优势；
- 失败轨迹严格为负优势；
- 失败严重程度仍影响负优势大小，违约购买比部分匹配受到更强抑制。

**符号保证：** 最大失败奖励为0。即使只有1条成功、其余失败尽可能低，组均值仍至少为`1/G² > 0`；只要有失败，均值又严格小于1。因此正负信号方向有保证。该保证只针对优势符号，不保证神经网络训练后每题表现单调改善。

只过滤全失败组会漏掉上述7条混合组中的正优势失败；只压缩失败奖励又不能阻止全失败组内部的相互排序。两者解决的是同一个目标一致性问题。

## 3. 代价与验收

冻结旧轨迹中有904个组符合新资格，全部满足“成功正、失败负”。旧记录508轮中358轮已包含至少两个新可用组；其余轮需要进一步补采，不能把该比例换算成确定的运行时长。旧策略按旧资格提前停止采样，离线审计不能预测新策略的轨迹和收益。

这一选择优先提高已具备成功路径的任务的稳定性；没有成功示例的困难任务暂时不提供更新，可能降低覆盖、增加采样成本。部分匹配在全失败组里的渐进学习信号也被放弃。不是任何任务都应采用此方案。

已通过26项相关测试。覆盖：真实环境比较器案例、严格成功边界、失败排序、不同组大小的最不利奖励组合、实际采样入口的过滤与补采、不可验证样本处理、日志与优势一致、旧配方和续训隔离。新旧原始Reward v3均保留，训练日志新增全失败过滤数、接受组成功/失败数及失败正优势计数，后者预期为0。

## 5. 方法依据与边界

[veRL的DAPO实现](https://verl.readthedocs.io/en/latest/algo/dapo.html#dynamic-sampling-with-group-filtering)支持按准确率过滤全成功/全失败组并补采；[DAPO论文](https://arxiv.org/abs/2503.14476)提供动态采样的实践依据。本项目在该思路上保留可验证约束及有界的失败排序，不声称是原样复现DAPO，也不引入其其他优化。

本方案是对训练目标的有意调整，不是保持最优策略不变的potential-based shaping，不能借用后者的理论保证。它是当前证据支持的优先实验，不是已证明全局最佳或必然提升的算法。
