# 阶段 2：初始学生 Baseline

## 目的与实现

测量领域训练前学生的真实起点，为后续 SFT、数据回流和 GRPO 提供同协议对照。模型为 `Qwen/Qwen3.5-2B`，revision `15852e8c16360a2fea060d615a32b45270f8a8fc`，关闭 thinking，temperature=0，每题一条有效模型执行轨迹。

新版评测复用采集侧同一环境、观察处理、Action Guard、预算和终止规则；严格成功要求完整 `gold_purchase`、`reward_valid=true`、`purchase_success=true`。每题最多 35 步，上下文 24,576 token，累计 response 20,480，每轮 assistant 512。服务错误单独处理，模型失败保留在固定分母中。

## 完整结果

| 集合 | 完成 | 严格成功 | 成功率 | 平均 Reward v3 | 平均步数 |
|---|---:|---:|---:|---:|---:|
| 开发集 | 300/300 | 3 | 1.0% | -0.1498 | 5.877 |
| 测试集 | 1,000/1,000 | 15 | 1.5% | -0.1039 | 5.748 |

两组均无缺失任务、无未解决基础设施异常。开发集 213/300、测试集 719/1,000 以连续非法动作终止，说明原始学生在当前工具协议下存在明显执行困难；不能仅凭这一现象推断根因或保证后续训练增益。

## 复用与边界

- 开发集用于诊断和选模；测试成绩用于最终同集比较，不能用于选择修复题或调参。
- Baseline 指领域训练前的后训练模型，不是纯预训练 `-Base` 权重。
- 外层历史 SFT/E1 使用不同数据与部分执行设置，不能与本表直接构成单变量消融。
- 汇总、终止分类和成功任务 ID 见 [baseline.json](../../results/baseline.json)；完整原始轨迹在本地 `next/outputs/baseline-v2/`，不混入 GitHub 文档。

源码入口、运行方法和冻结清单见[执行说明](../execution.md)。后续模型使用同一冻结测试集、执行协议和完整分母。
