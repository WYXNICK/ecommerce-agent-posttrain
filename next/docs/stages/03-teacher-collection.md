# 阶段 3：教师轨迹采集

## 目的与实现

让强模型真实操作购物环境，生成可直接训练学生的完整成功示范。教师只看 Actor 可见信息；严格 JSON 动作转成统一工具调用，由共享守卫在真实环境执行，不需要教师 logits、tokenizer 或私有思维链。

Sol 固定为 `gpt-6.1-sol-2026-09-29`、high 推理；环境、观察、工具和学生可见预算与 Baseline 一致。使用 4,000 道训练候选和 800 道验证候选，按九领域配额采集；每教师 6 路并发。429 最多尝试 12 次，等待 2/4/8/16 秒后每次 20 秒；耗尽后保存进度退出，可在同协议下续跑。HTTP 重试不重复执行环境动作。

只有完整严格成功、通过学生模板/长度/监督检查且 task ID 唯一的轨迹才进入成品。基础设施失败与模型行为失败分别记录；原始轨迹及失败保留为证据，不把失败样本静默计成成功。

## Sol 已完成结果

| 指标 | 训练采集 | 验证采集 |
|---|---:|---:|
| 实际尝试的独立任务 | 2,449 | 240 |
| 严格成功、验收成品 | **2,000** | **200** |
| 首次有效模型行为严格成功率 | **81.67%** | **83.33%** |
| 基础设施中断 episode | 3 | 0 |
| 含基础设施中断的总 episode | 2,452 | 240 |
| 含基础设施的采集产出率 | 81.57% | 83.33% |
| 成品平均步骤 | 9.66 | 9.50 |
| 成品平均 / 最大序列 token | 7,383 / 22,290 | 7,262 / 21,311 |

完成时间：北京时间 2026-10-28 22:01。实际每个任务只有一次有效模型行为尝试；没有靠行为重采达到上述成功率。训练侧 449 条模型失败中，部分满足购买 192、response 超预算 136、提前放弃 74、循环 38，其余 9；失败分类与完整统计见 [teacher-sol.json](../../results/teacher-sol.json)。

**81.67% 是已尝试训练候选上的整题执行成功率。** 验证侧为 83.33%；它不是全部 4,000/800 道候选的成绩，也不是 1,000 题测试成绩。按成功数和领域配额停止采集，不能据此宣称教师泛化能力为 81.67%。成品经过成功筛选，成品 100% 成功也不代表教师能力为 100%。

## 验收、成品与下一步

- 成品与严格成功原始证据逐条一致，教师快照一致；领域配额、唯一任务、模板长度和 assistant 监督范围通过验收。
- 训练/验证交集为零，训练与受保护留出集合无重叠；继承证据的原始文件哈希不变。
- 已发布 [Sol 数据目录](../../data/teacher/sol/manifest.json)：`train.jsonl.gz` 2,000 条、`validation.jsonl.gz` 200 条；gzip 解压后与验收成品逐字节一致，压缩与原文 SHA-256 均记录在 manifest。
- 原始轨迹、重试、usage 和完整验收记录保留在本地 `next/outputs/teacher-parallel/` 及只读继承源；成品是训练输入，不能替代原始终局证据。API 未返回的重试费用未伪称完整计费。
- Astra 独立采集中，尚未形成完整交付，不混入 Sol 的数量和统计；本地实时报告为 `next/docs/teacher-astra-parallel.md`。

下一步可直接用 Sol 成品适配新版 SFT，无需等待 Astra。初始示范可以重复训练；后续两轮失败回流仍需教师真实接管生成修复数据。新版 SFT、失败回流和 GRPO 尚未执行。

## 教师正式评测如何安排

采集质量统计应保留，但不是独立基准评测。针对本项目，建议最终补一次教师在同一冻结 1,000 题上的参考结果：固定模型快照、提示与执行预算，每题一次有效行为，失败计入完整分母，单列成本。它不阻塞 SFT；不得根据教师测试失败改题或回流测试轨迹，也不把教师成绩称为学生的理论上限。

原项目曾报告 DeepSeek V4 Flash 的历史 Final-200 结果 139/200（69.5%），后来的 75.96% 是删题后的分母重算；与新版测试或 Sol 采集成功率均不可直接比较。[原项目审计](https://github.com/YYHDBL/shopping-grpo-longhorizon/blob/main/docs/evaluation-updates.md)
