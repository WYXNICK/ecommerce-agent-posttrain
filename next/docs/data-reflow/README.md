# 第一轮失败数据回流与增量 SFT 对照

## 目的

检验定向纠错是否比普通新增成功示范更有效，为 GRPO 选择可靠起点。只做一轮；第二轮须根据实际收益另行决定。不承诺 GRPO 必然提高成功率。

## 方法与固定范围

| 环节 | 实现 |
|---|---|
| 起点 | 新版 S0：Astra 2,000 条示范训练的 Qwen3.5-2B，按 dev300 规则选择 |
| 失败采集 | 在教师候选池中排除 S0 已用 2,000 题，执行余下 2,000 题；固定哈希顺序、原执行预算和守卫 |
| 干预位置 | 优先选首次守卫拒绝或相同可见状态下的重复动作；否则取失败购买前。它是可验证的接管位置，不宣称定位了语义上的首个因果错误 |
| 教师修复 | 环境 reset 后真实重放学生前缀，逐轮校验可见消息一致，Astra 接管继续执行；不向教师提供隐藏目标、评测奖励或失败答案 |
| 验收 | 严格成功终局、无服务错误、长度和学生模板合格；仅监督教师接管后的 assistant 动作，学生前缀与环境观察全部 mask |
| 数量 | 目标 300 条；候选耗尽时如有至少 100 条则按真实数量进行配对实验，否则停止并汇报。不开第二轮凑数 |
| 普通示范对照 | 从独立训练备用池采集相同数量的 Astra 完整成功轨迹，领域计数与修复组一致；不根据学生是否失败筛选，任务与 S0/修复组不交叉 |
| 原数据回放 | 两组均混入同一批 S0 原始示范，与新增数据按条数 1:1 混合，缓解遗忘 |
| 增量训练 | 都从同一个 S0 独立初始化 LoRA；2 epoch、LR 2e-5，其余沿用已验证的双卡 SFT 配方；每 epoch 保存并运行 dev300 |
| 选模 | 每组按严格成功数→平均奖励→较少步骤→较早检查点选择；再与 S0 比较，同指标完全相同时保留 S0 |

普通组与修复组匹配教师、领域计数、新增样本数、回放样本、优化器更新次数和选模规则。修复组只监督后缀，**监督 token 不完全相同**；准备清单记录两组实际输入/监督 token，训练记录 GPU 时间。该对照检验的是整套定向修复策略，不单独证明“后缀 mask”或某个环节的因果收益。两组难度也不保证一致：普通组不按失败选题，这是本对照的设计区别。

不可验证终局和基础设施失败不混作模型错误；没有可靠接管位置的失败只记录，不推测错误点。原始失败、回放不一致、教师失败和接收成品全部留有证据。保持原执行循环、Reward v3、观测投影、预算与严格成功定义不变。

## 执行与成品

权威配方：[reflow.json](../../configs/reflow.json)；入口：[run.py](../../scripts/reflow/run.py)。已冻结修复与普通示范成品，可直接用 `--frozen-data` 进入配对训练，不重复调用教师；校验成品哈希、任务隔离、回放 ID、token 与监督范围。采集源模型保留在原始数据证据中，不能将复用数据称为当前模型新采集的在线失败。

本轮配对训练与开发集选模已完成：S0 220/300、普通组 218/300、修复组 226/300；选中修复组 step 72。收益与代价、单种子和开发集选模的限制见[结果汇总](results.md)。运行方式与备份见[运行与模型保存](../sft/runtime.md)。结果写入 `results/data-reflow/r1/summary.json`。只在训练池构造纠错数据，开发集用于选模，最终测试仍锁定。

## 已完成的数据准备

| 阶段 | 结果 |
|---|---|
| 学生失败采集 | 完成 2,000 题，严格成功 1,383（69.15%），失败 617；这是训练候选池，不是开发/测试成绩 |
| 教师回放修复 | 对有明确接管位置的 491 条尝试修复，144 条严格成功并可训练（29.33%）；其余不进入训练 |
| 普通示范对照 | 179 次执行中接收 144 条（80.45%），领域计数与修复组完全相同 |
| 实际训练规模 | 每组 144 条新增＋相同 144 条原示范，共 288 条；2 epoch、72 次更新 |

修复数量未达到 300 目标；候选耗尽后按预先设置的最低 100 条门槛继续实际 144 条对照，不扩大范围凑数。修复和普通采集面对不同任务及起始状态，两个接收率不能解释为教师能力变化。两组每 epoch 的监督 token 分别为 57,388 / 64,692，输入 token 为 2,762,898 / 2,006,303；不宣称等 token 或等计算成本。

数据成品的压缩/内容哈希、144＋144 条唯一任务、留出隔离和严格成功原始证据已核验。[采集结果](../../results/data-reflow/r1/collection.json)与[冻结数据清单](../../data/reflow/r1/manifest.json)保留完整来源。普通组和修复组的最终收益依据当前模型评测，不预设哪组获胜。
