# 新版实现边界

继承仓库根目录 `AGENTS.md` 的运行契约与开发原则。

- 本轮及后续完善版本的代码、配置、数据、测试和结果说明放在 `next/`。
- 外层开源代码、原有数据与历史实验保留作参考，不为新版适配而修改。
- 复用某个模块并需要修改时，先复制到 `next/`，再调整实现、导入和配置；未复制的外层实现仅可只读调用。
- 商品库、搜索索引、模型等大文件可只读复用或使用外部存储，不为目录隔离重复存放；在新版配置及清单中记录来源和校验信息。
- 新训练除隔离外层 `data/evaluation/tasks.jsonl` 外，还须保护本目录冻结的验证、开发、测试任务及重复组，按 `docs/data-preparation.md` 使用留出清单。测试不得用于选模、修复回流或调参。
- 新版结果单独报告；外层 SFT/E1/E2/E3 属于历史参考，不能混入新版实验表冒充同协议对照。
